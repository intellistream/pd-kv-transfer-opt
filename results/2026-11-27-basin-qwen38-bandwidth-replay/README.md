# Qwen3.8-27B Basin 带宽回放

CPU 回放使用 Qwen3.8-27B 原生 **200 Gbps/口** 的五轮实测作输入，包括 3,738 条 rank 交接调用、实际输出量及 D 引擎计数。低带宽档模拟按接收 worker 串行化与端口限额重算交接，按最慢 rank 决定 KV 就绪，再按观测流并发宽度拟合 D 服务速率并传播到会话后继。每条请求实际输出、已观测的路由、P 服务与原页分配延迟保留在模型中。200 Gbps 输入按实测锚定。 [200 Gbps 实测](../2026-11-26-basin-qwen38-200g-per-port/README.md)
